# Mi web — Ruth Sainz

Web personal estática realizada con HTML, CSS y JavaScript, con estética morada coherente con el portfolio y el currículum.

## Archivos
- `index.html`: contenido y estructura.
- `styles.css`: estilos, colores y diseño responsive.
- `script.js`: menú móvil.

## Verla en local
Abre `index.html` en el navegador.

## Publicarla en GitHub Pages
1. Crea un repositorio, por ejemplo `Mi-web`.
2. Sube `index.html`, `styles.css`, `script.js` y este README a la raíz.
3. En GitHub entra en **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`.
5. Guarda y espera a que GitHub Pages publique la página.

Los enlaces al portfolio y al currículum ya apuntan a las direcciones facilitadas. El contenido se puede editar directamente en `index.html`.
